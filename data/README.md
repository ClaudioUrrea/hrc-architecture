# Deposited data

All files are outputs of the software running against simulated interfaces, or synthetic reconstruction datasets generated from the article's summary statistics (see Provenance below). See
`schemas/` for the JSON Schema of each file and `../docs/REPRODUCE.md` for the
script that consumes it.

| File | Rows | Description |
|---|---|---|
| `plc_runs.csv` | 12 | Per-run commissioning times, three toolchains, with the per-step decomposition |
| `effort_log.csv` | 10 | Task-level porting hours with the counted/not-counted flag of Appendix C |
| `faults_450.csv` | 166 | Fault events over the 200 h campaign: category, time, population flags (logged); detection, recovery and operator time (**re-derived in v2.1.0** by `tools/reconstruct_faults.py` to the statistics of Table 9 and Section 8.4) |
| `interfailure.csv` | 156 | Service-affecting inter-failure intervals entering the Weibull fit |
| `cloc_lizard.json` | - | Line counts and cyclomatic complexity per module |
| `conformance_log.csv` | - | Interface conformance runs (Table 4) |
| `cycles_36M.parquet` | 3.6e7 | Control-cycle telemetry, 120 blocks x 100 min (**generated**; Figshare only, ~520 MB; `make data`) |
| `stage_timings.parquet` | 8,000 | Per-stage durations of 1,000 instrumented cycles + two 1,000-run benchmarks (**generated**) |
| `protocol_samples.parquet` | 1.2e5 | Protocol transaction latencies (**generated**) |
| `ablation_cycles.parquet` | 2.1e6 | Per-cycle timing, 7 configurations x 30 cells x 10,000 cycles (**generated**) |
| `segments_30.parquet` | 390 | 13 series x 30 segment means: proposed, 6 tuned and 6 untuned baselines (**generated**) |
| `tuning_grid.parquet` | 480 | One-parameter sweeps, 6 baselines x 5 values x 10 tuning segments + the 30 comparison segments (**generated**) |
| `cbf_dataset_66d.npz` | 5.5e4 | Barrier training (40,000), held-out (10,000) and gray-zone (5,000) sets + trained weights (**generated**) |
| `provenance.json` | - | Tool, seeds, library versions and SHA-256 of the files above |

> **Provenance.** The seven files marked *generated* are reference reconstruction datasets: synthetic, deterministic
> (fixed-seed) datasets generated by the deposited tools from the summary statistics printed in the manuscript,
> released so that every published figure, table and test can be regenerated and independently checked. `make check` verifies that the analysis
> pipeline reproduces the published numbers from them. The Data Availability statement of the article states the same.

## Population definitions

Fixed in Section 8.3 of the paper **before** the analysis and not adjusted
afterwards. `all_faults` = 166. `service_affecting` = 156; the ten configuration
inconsistencies are excluded because they are rejected before application and
consume no production time. `operator_intervention` = 6, the network-partition
events. No transient-duration filter is applied: such a filter would be a
post-hoc choice made after seeing the intervals.

## Censoring

The run terminates at 200 h, so the final interval of the sequence is
right-censored and enters the Weibull likelihood through its survival term (dropping it is reported as a sensitivity check). The exact Poisson
intervals use the full 200 h exposure and are unaffected.
